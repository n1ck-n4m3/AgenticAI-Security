# 已读论文：局限与可改进点

> 来源：2026-08-10 组会 P1（教授要求：读论文要双向——能替作者辩护，也能批评假设）。  
> 覆盖：五篇 MAS 防御精读 + 攻击/基准五篇（TAMAS / Conjunctive / NetSafe / ASB / CORBA）。

读法：每篇先写 **作者可以怎么辩**，再写 **我们能打的缺口**（对应 proposal：trust + recover）。

---

## A. 五篇防御

### A1. G-Safeguard（监督检测 + 剪边）

**作者可辩**  
- 问题清楚：MAS 毒性沿拓扑传，单点 LlamaGuard 不够。  
- 检测+修复闭环完整（相对只测 ASR 的攻击文）。  
- 归纳迁移：小图训、大图测；跨 LLM backbone。  
- 多攻击面：PI / tool / memory，不是一种玩具攻击。

**局限**  
1. **必须有攻击者标签** → 未知攻击、新手法会掉点（BlindGuard 的动机）。  
2. **修复 = 剪边/隔离**，无 recover、无清 memory、无回滚工具副作用。  
3. 异常种类漂了就不稳（监督分布假设）。  
4. 评测大量 CSQA/MMLU/GSM8K，工具/记忆场景相对薄。  
5. 假阳性：风格特异的良性 agent 可能被剪。

**可改进**  
- 检测器当传感器，不要给它死刑权。  
- 隔离后加确诊 + 可验证重置（canonical role + 清 history）。  
- 压测自适应攻击 / 合取攻击（Conjunctive）看剪边是否还够。

### A2. BlindGuard（无监督 + corruption）

**作者可辩**  
- 现实中没有全套攻击标签；只用正常交互 + 语义腐蚀模拟未见攻击。  
- 层次编码（自身 / 邻居 / 全局）比只看整图或只看单点更合理。  
- 同配置有时弱于 G-Safeguard，但泛化/换模型时更强——卖的是 **unknown attacks**。

**局限（会上已对齐）**  
1. **只隔离，不恢复**；节点越删越少（海军五船场景不可接受）。  
2. **不够细粒度、不可解释**（XG-Guard 的动机）。  
3. 假设「加噪后节点显著离群」——正常 agent 本就有差异（观测不同、能力不同）。  
4. 「unknown」评测仍大量对标 G-Safeguard 三类攻击。  
5. 异常 ≠ 恶意：更聪明/信息更多的 agent 也可能被当离群（**假阳性伤 trust**）。  
6. 从「干净常态」学正常——若一开始就不干净，假设崩。

**可改进**  
- 连续信任分 + 观察期，不要二值剪死。  
- 区分「偏离」与「更知情」（需要任务效用 / 交叉验证，不只图离群）。  
- 加 recover：重置会话 / 换干净实例 / 复职爬坡。

### A3. XG-Guard（token 级 + 可解释）

**作者可辩**  
- 补 BlindGuard：细粒度 + 解释（token 热力图）。  
- 通信层观测、不看私有记忆——更贴近现实防御者。  
- 主表 AUC 往往高于 BlindGuard。

**局限**  
1. 处置仍多是 **整节点隔离**；解释没有接到修复动作（会上：可改词/改 memory 而不是杀节点）。  
2. 更敏感 → FN↓ 但 **FP↑**。  
3. 「偏离主题」可能只是跑题，不是攻击。  
4. 同样假设初始全干净。  
5. 解释质量缺少严格人类评测 / 因果验证。

**可改进**  
- 解释 → **可验证动作表**（删 token、截断 history、写回模板），runtime 执行而非 LLM 乱改。  
- 报告 FP/FN 与效用，不只 AUC。

### A4. GUARDIAN（时序图重构）

**作者可辩**  
- 把「跨轮传播」做成一等公民（Transformer + 时序属性图）。  
- 无监督重建，统一幻觉放大与错误传播。  
- 信息瓶颈压缩交互图。

**局限**  
1. 仍是 **删最可疑节点**，无 recover。  
2. 增量训练偏同分布；分布一变要小心。  
3. FDR 可到 ~30% 量级（误杀贵）。  
4. 公式/设定重，落地与开源完整度需核对。  
5. 时间建模很强，但 **trust 随时间恶化/恢复** 没有显式状态机。

**可改进**  
- 把重建误差当连续信任证据，而不是一轮死刑。  
- 接触者检疫（听过坏节点的邻居短暂隔离）。  
- 与 GUARDIAN 时序编码器对接「信任轨迹」。

### A5. Resilience（结构韧性 + Challenger/Inspector）

**作者可辩**  
- 问对了：故障下哪种拓扑更抗；如何用角色机制恢复。  
- Hierarchical 更抗；C+I 可挽回大量损失。  
- AutoTransform/AutoInject 可复现故障。

**局限**  
1. 偏合成错误/笨拙 agent，不是完整自适应攻击者。  
2. Inspector 自己可被注入；无「可验证执行」。  
3. 常驻多一次 LLM → 贵。  
4. 无图检测；单故障设定为主。  
5. 无状态回滚 / 工具副作用。

**可改进**  
- Inspector **按需唤醒**（先图检测再审）。  
- 与隔离状态机组合，而不是每轮全审。

## B. 攻击与基准（本次 P1 加读）

### B1. TAMAS（教授点名，MAS 对抗基准）

**作者可辩**  
- 补单 agent bench 缺口：真实 Autogen/CrewAI、多场景、六类攻击、ERS 安全–效用权衡。

**局限 / 对我们**  
- 偏框架配置与任务场景，**不是** G-Safeguard 那套 utterance-graph GAD 评测。  
- 防御论文若只在 CSQA 刷 AUC，拿到 TAMAS 上可能崩。  
- **应用**：新方法至少报一类 ERS/效用，不要只报 ASR。

### B2. Conjunctive Prompt Attacks（教授点名）

**作者可辩**  
- 结构性漏洞：触发键 + 隐藏模板单独都良性，路由会合才激活；单消息护栏失效。

**局限 / 对我们**  
- 现有 GAD（看单轮话语离群）**可能看不见合取**：每一跳都不像「整句很毒」。  
- BlindGuard/XG-Guard 的「未知攻击」未必覆盖这种 **组合激活**。  
- **应用**：trust 对象应是 **路径/组合信息流**，不是单点文本；防御要能推理路由。

### B3. NetSafe（拓扑安全现象）

**作者可辩**  
- 首次把拓扑当安全变量；幻觉放大、聚合安全、瓶颈；越密越大往往越脆。

**局限**  
- 发现问题为主，**几乎不给自愈协议**。  
- 静态拓扑结论 ≠ 动态改拓扑一定更安全（TopoSHIELD 才走那步）。

### B4. ASB（单 agent 攻防基准）

**作者可辩**  
- 工具/记忆/注入形式化最全的 agent bench 之一；G-Safeguard 族的 TA/MA 源头。

**局限**  
- **单 agent / 工具 agent** 为主，抓不住协作传播与合取路由。  
- 对我们：威胁分类可借，评测不能只停在 ASB。

### B5. CORBA（协作拒绝服务）

**作者可辩**  
- DoC：语义良性的递归阻塞，对齐护栏看不到；传播瘫痪协作。

**局限 / 对我们**  
- 「离群语义」检测可能 **检不出**（话看起来正常，行为是空转）。  
- 自愈还要管 **可用性/资源**，不只答错题。

## C. 跨论文的共同缺口（组会可直接讲）

| 缺口 | 几乎谁都停在这 | 我们可做 |
|------|----------------|----------|
| Recover | 剪边/删节点 | 隔离 → 确诊 → 重置/杀/复职 |
| Trust 连续化 | 二值异常 | 分数爬坡、观察期 |
| FP：更好的 agent | 当离群 | 交叉验证 + 效用约束 |
| 组合攻击 | 单句/单节点 | 路由/合取/路径信任 |
| 可用性攻击 | 不管空转 | 行为/资源异常 |
| 可验证修复 | LLM 建议 | runtime 只执行可检查动作 |
| 安全–效用 | 只报 ASR/AUC | ERS 或 Pareto |

**一句话给教授**：现有防御把「异常」当成「该剪掉的坏人」；我们要把异常当成 **信任证据**，在强攻击面下做 **可逆自愈**，并显式处理合取与误报。
