# 2025-2026 additions (relative to an earlier 62-paper list)

Coverage check against [multiagent_security_corpus](https://github.com/BrookeYangRui/multiagent_security_corpus) Set 1 (mature MAS security) plus a few high-citation Set 1 preprints. Priority venues: NeurIPS, ICML, ICLR, ACL, EMNLP, AAAI, USENIX Security, IEEE S&P, NDSS, COLM, WWW; then AACL, ESORICS workshop, IEEE IRI, CSUR, AI Open.

The original 62-paper list required a top-venue acceptance and excluded arXiv-only work. This pass is slightly broader: graph-detector papers that sit next to G-Safeguard, and preprints already over the corpus maturity line (citation count at least 10), are included (SentinelAgent, SAFEFLOW, BlockA2A).

Star = added in this pass. This public repo stores links and English notes only.

## Highest-priority relative to graph detectors and recovery

| Paper | Venue | Why it matters now |
|---|---|---|
| When Embedding-Based Defenses Fail | ICML 2026 | Directly attacks embedding / graph anomaly detectors (Slow Drift, Benign Wrapper, Chaos Seeding). BlindGuard and XG-Guard need a response. |
| SentinelAgent | arXiv 2025 (high citation) | Graph anomaly detection in the same family as G-Safeguard, different monitor placement. |
| SentinelNet | WWW 2026 | Decentralized reputation plus neighbor pruning; no central monitor. |
| Cowpox | ICML 2025 | Cure samples that spread through interaction: recovery, not only isolation. |
| Control-Flow Hijacking + ControlValve | ICLR 2026 | Attack uses routing / confused-deputy, not semantic outliers; current GAD may miss it. |
| Multi-Agent Systems Execute Arbitrary Malicious Code | COLM 2025 | Control-flow hijack to arbitrary code execution. |
| ResMAS | AAAI 2026 | Treats resilience as searchable topology plus prompts; follows Resilience. |
| Byzantine Reliability (CP-WBFT) | AAAI 2026 | Confidence-weighted aggregation without first naming the adversary. |
| MASLeak | USENIX Security 2026 | Black-box extraction of MAS prompts, topology, and tool IP. |
| A2ASecBench | ICLR 2026 | Protocol-layer A2A benchmark, not a dialogue-graph GAD bench. |
