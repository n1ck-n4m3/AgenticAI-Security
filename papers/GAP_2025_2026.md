# 2025–2026 补漏（相对原 62 篇顶会清单）

对照 [multiagent_security_corpus](https://github.com/BrookeYangRui/multiagent_security_corpus) 的 Set 1（成熟 MAS 安全）+ 少量高引用 Set 1 预印本。优先 **NeurIPS / ICML / ICLR / ACL / EMNLP / AAAI / USENIX Security / S&P / NDSS / COLM / WWW**，其次 AACL、ESORICS workshop、IEEE IRI、CSUR / AI Open。

原清单只收「顶会已录用、无 arXiv-only」。这次放宽了一点：图检测族直接相关、引用已过 corpus 成熟线（≥10）的预印本也收了（SentinelAgent、SAFEFLOW、BlockA2A）。

★ = 本次新补。本仓库只放链接；本地研究库另存 PDF。

## 必读（和当前 G-Safeguard 族 / self-healing 最贴）

| 论文 | Venue | 为什么现在补 |
|---|---|---|
| ★ When Embedding-Based Defenses Fail | ICML 2026 | 直接打 embedding/图异常检测：Slow Drift、Benign Wrapper、Chaos Seeding。BlindGuard / XG-Guard 必须回应。 |
| ★ SentinelAgent | arXiv 2025（高引） | 图异常检测，和 G-Safeguard 同族、监控位置不同。 |
| ★ SentinelNet | WWW 2026 | 去中心信誉 + 剪邻居，无中心监视器。 |
| ★ Cowpox | ICML 2025 | 「治愈样本」在交互中传播，是少有的真正 recovery 而不仅 isolation。 |
| ★ Control-Flow Hijacking + ControlValve | ICLR 2026 | 攻击走路由/confused deputy，不是语义离群；现有 GAD 可能看不见。 |
| ★ Multi-Agent Systems Execute Arbitrary Malicious Code | COLM 2025 | 控制流劫持导致任意代码执行；Shmatikov 组，引用高。 |
| ★ ResMAS | AAAI 2026 | 把韧性当成可优化的拓扑+prompt，接 Resilience。 |
| ★ Byzantine Reliability (CP-WBFT) | AAAI 2026 | 用置信加权聚合，而不是先找出坏人。 |
| ★ MASLeak | USENIX Security 2026 | 黑盒抽 MAS 的 prompt/拓扑/工具 IP。安全四会里真正的 MAS 攻击。 |
| ★ A2ASecBench | ICLR 2026 | Agent-to-Agent 协议层基准，不是对话图 GAD 基准。 |
